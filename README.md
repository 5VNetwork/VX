**VX**（曾用名 Vproxy）是一款免费、完全开源的全平台**代理客户端**，可用来当作 **梯子** 进行 **科学上网**、**翻墙**。支持 Windows、macOS、Linux、Android、iOS，导入机场订阅即可连接。

官网下载：[vx.5vnetwork.com](https://vx.5vnetwork.com)

## 为什么用 VX 科学上网、翻墙

- **完全开源**：自动构建与发布，代码可审计，100% 安全可靠
- **容易使用**：开箱即用，容易上手
- **当梯子用**：支持常见机场订阅与代理节点，一键科学上网
- **全平台**：同一套客户端覆盖电脑和手机

## 功能特点

- **主流协议**

## 面向机场主的深度链接说明

### 格式 1

```
vx://add/sub://<base64_encoded_url>?remarks=<subscription_name>
```

**示范:**

```
vx://add/sub://aHR0cHM6Ly9leGFtcGxlLmNvbS9hYmNk?remarks=%E6%9C%BA%E5%9C%BA%0A
```

### 格式 2

```
vx://install-config?url=<subscription_url>&name=<subscription_name>
```

**示范:**

```
vx://install-config?url=https%3A%2F%2Fexample.com%2Fabcd&name=%E6%9C%BA%E5%9C%BA%0A
```
